# Glossary — NTFS-Silicon

| Term | Means | Not |
| --- | --- | --- |
| Volume | A formatted storage area the Mac can mount (a partition of a disk) | drive, disk, device |
| Disk | The physical or virtual device holding one or more volumes | |
| Mount | Make a volume's files visible in Finder | attach, connect |
| Unmount | Make the volume invisible without disconnecting the disk | detach |
| Eject | Unmount every volume of a disk and power off / disconnect it | remove |
| Verify | Read-only check of the volume's filesystem for errors | repair, fix |
| Erase | Delete all data and create a new filesystem on a volume | format (verb), wipe |
| Format | The filesystem type a volume uses (menu pick in Erase) | system |
| Mount point | The folder under /Volumes where a mounted volume lives | path |
| Status dot | Colored dot on a volume row, always paired with a word (Ready / Read-only / Unmounted) | indicator |
| Capacity bar | Horizontal bar splitting a volume's used space by category | chart |
| Volume menu | The status-bar extra panel | menu bar app, tray |
